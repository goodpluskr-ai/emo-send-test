# 이모 전송 시험 (안드로이드 시험용 앱)

나만의 사진·이모 앱을 본격적으로 만들기 전에, **카톡 대화방에 그림을 넣는 방법이 실제로 되는지**만 확인하는 작은 앱입니다.

| 시험 | 확인할 것 |
|---|---|
| 1. 복사 → 붙여넣기 | 그림을 복사해 카톡 입력창에 붙여넣으면 **그림으로** 들어가는가 |
| 2. 전용 키보드 | 키보드에서 그림을 누르면 카톡에 **바로** 들어가는가 (키보드가 지원 형식을 자동 기록) |
| 3. 공유하기 | 카톡으로 공유하면 잘 가는가, 대화방을 다시 골라야 하는가 |
| 4. 떠 있는 버튼 | 카톡 위 분홍 버튼 → 그림 탭(복사) / 길게(공유)가 편한가 |
| 5. 받은 그림 저장 | 카톡에서 받은 그림을 '공유'로 이 앱에 저장할 수 있는가 |

견본 그림 4장(PNG 2장, 움직이는 GIF 1장, 사진 JPG 1장)이 들어 있고, 내 그림도 추가할 수 있습니다.

## APK 만드는 방법 (둘 중 하나)

### A. GitHub에서 자동으로 만들기 (컴퓨터에 아무것도 설치 안 해도 됨)
1. GitHub에서 새 저장소(Private 가능)를 만들고 이 폴더의 파일을 모두 올립니다.
2. 저장소의 **Actions** 탭 → '시험 앱 APK 만들기'가 자동으로 실행됩니다 (약 5분).
3. 끝나면 실행 기록을 눌러 아래쪽 **Artifacts → emo-send-test-apk**를 내려받습니다.
4. 압축을 풀면 `app-debug.apk`가 있습니다.

### B. Android Studio로 만들기
1. Android Studio → Open → 이 폴더 선택
2. 휴대폰을 USB로 연결(개발자 옵션·USB 디버깅 켜기) → ▶ Run

## 휴대폰에 설치
- `app-debug.apk`를 휴대폰으로 옮겨 누르면 설치됩니다.
- "출처를 알 수 없는 앱" 경고가 나오면 이번만 허용해 주세요. (시험용이라 Play 스토어를 거치지 않기 때문)

## 시험 순서
1. 앱을 열고 **시험할 그림**을 고릅니다.
2. 시험 1~5를 차례로 해 보고, 각 시험의 결과 버튼을 누릅니다.
3. 맨 아래 **결과 복사**를 눌러 Claude 대화창에 붙여넣습니다.

PNG, 움짤(GIF), 사진(JPG)을 각각 시험하면 형식별 차이까지 알 수 있습니다.

## 시험이 끝나면
설정 → 애플리케이션 → 이모 전송 시험 → 삭제
(키보드 시험을 했다면 키보드를 원래 키보드로 바꿔 두세요.)
